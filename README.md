# Temperature Converter

## Project Description
The Temperature Converter is a simple web application that converts temperature values between Celsius, Fahrenheit, and Kelvin. This project was created to understand basic JavaScript logic, user input handling, and DOM manipulation.

## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and user-friendly interface
- Instant result display

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
- User enters a temperature value
- User selects the temperature unit
- Clicks the convert button
- Converted temperature is displayed instantly
